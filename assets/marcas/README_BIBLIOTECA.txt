BIBLIOTECA DE MARCAS DAEDALUS

Para agregar una marca permanente:
1. Copia el PNG transparente dentro de esta carpeta.
2. Añade una entrada a catalogo.json:
   {
     "nombre": "Nombre visible",
     "archivo": "nombre-del-archivo.png"
   }
3. Sube/reemplaza esta carpeta en GitHub.
4. Espera el despliegue de GitHub Pages y abre Daedalus una vez con internet.

La opción de carga manual dentro de la interfaz sigue siendo temporal y no modifica GitHub.
